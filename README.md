# Homework5
一、作品構想
我希望製作一個可以直接在瀏覽器遊玩的踩地雷遊戲，讓玩家透過數字線索判斷地雷的位置，練習觀察與邏輯推理。作品名稱為「雷區漫遊」，採用繁體中文介面與柔和綠色風格。

二、主要功能
遊戲提供初級、中級及高級三種難度，分別為 9×9 格與 10 顆地雷、16×16 格與 40 顆地雷、30×16 格與 99 顆地雷。每次重新開始都會重新產生棋盤，首次翻開的格子及周圍八格保證安全。

玩家可以翻開格子或插旗。數字表示周圍八格中的地雷數量；沒有相鄰地雷的空白區域會自動展開。翻開所有安全格即可獲勝，踩到地雷則遊戲結束。

三、輸入與輸出
輸入包含選擇難度、點擊格子、切換翻開或插旗模式，以及重新開始。輸出包含棋盤數字、旗標、地雷位置、剩餘旗標數、經過時間、探索進度及勝敗提示。

四、操作與紀錄
電腦使用滑鼠左鍵翻開、右鍵插旗；手機可透過模式按鈕切換操作。遊戲會保存各難度的最佳獲勝時間，紀錄僅儲存在目前瀏覽器，不會跨裝置同步。大型棋盤可以捲動查看。

五、技術與實作方式
利用 AI 協助整理需求及產生程式，以 HTML 建立頁面結構、CSS 設計介面，並使用 JavaScript 實作地雷配置、相鄰地雷計算、空白區域展開、計時及勝敗判定。所有程式整合於單一 index.html，不需要後端伺服器或額外套件，可透過 GitHub Pages 發布。
